La aplicacion no esta conectada al servidor

Ejecuta python app.py y abre http://localhost:8000 en el navegador. No abras el archivo index.html directamente: sin el servidor, el analisis no puede funcionar.

Que quieres analizar?

Elige la red social en la que estan los comentarios que te preocupan. El servicio extrae 40 features de cada comentario y aplica 9 heuristicas ponderadas para estimar el porcentaje de bots, con su distribucion por veredicto.

Por que aqui el procedimiento es distinto

YouTube deja leer sus comentarios por API publica (basta una URL). Las demas redes cierran esa via: exporta los comentarios con una herramienta web (CSV/JSON) y sube el archivo aqui. El motor de analisis es el mismo.

Método universal (cualquier red social)

Sirve para cualquier app o red social. Va limitado en el número de comentarios, ideal para cantidades pequeñas:

es.exportcomments.com

Como subir el archivo

Arrastra aqui tu archivo o selecciona uno Ningun archivo seleccionado CSV o JSON · maximo 16 MB · hasta 10.000 comentarios
